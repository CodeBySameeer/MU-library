# MU Library

Free study resources for Mid-West University students — notes, past papers, syllabi, and assignments across all faculties.

## Features

- 📚 Multi-faculty subject browser (BE, BSc, BBA …)
- 🔍 Global search with suggestions + recent searches
- ⭐ Favorites, recently viewed, offline-first downloads
- 🌗 Dark mode, accent picker, command palette (`Ctrl+K`)
- 📱 PWA-installable, works offline
- 💬 AI chat assistant (Groq-backed)
- 📊 Maintainer insights at `#/admin`
